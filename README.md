# Project Repository

This repository contains a minimal scaffold for a Simple Task Manager project.

## Website

A small static website lives in `website/`.

### View locally

Open `website/index.html` in your browser (or serve the folder with any static server).

Example (optional):

- `python -m http.server` (run inside `website/`, then open http://localhost:8000)

## Notes

- The navbar brand/logo links to https://fruit.com.
- The footer includes a dynamic current year rendered via `website/script.js`.
